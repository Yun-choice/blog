그로스 해킹은 핵심 지표를 찾고, 그 지표를 성장시키는 방법을 찾는 활동이라 할 수 있다.^[[그로스 해킹의 시작, PMF와 AI 패러다임 변화]]
여기서 지표를 관리하는 방법은 대표적으로 과업 기반(Task-based)과 프레임워크 기반(Framework-based) 둘로 나뉜다. 

# 과업 기반(Task-based)

각 조직/부서별로 담당하는 업무를 우선 정의한 후 해당 업무를 통해 발생하는 수치들을 지표화해서 관리하는 것

과업 ---> 지표

_예시:_

| 부서  | 지표                       |
| --- | ------------------------ |
| 마케팅 | CTR, ROAS 등              |
| 운영팀 | CS 건 수, 리뷰수, 평균평점 등      |
| 개발팀 | 버그픽스, 채택률                |
| 사업팀 | 신규 계약 건수, Churn MRR, ASP |
### 장점
- 팀 내 의사소통 원할
- "놀지 않았다"의 강력한 증거
### 단점
- 전체적으로 서비스 관점에서 무엇이 중요한 지표인지 판단하기 어려움
- 팀별 진행 중인 업무의 변경 => 모니터링 지표 변경
- '성장'에 활용하기 어려움

# 프레임워크 기반(Framework-based) ― AARRR

서비스 이용흐름에 따른 핵심 퍼널과 지표를 정의하고, 해당 지표를 개선하기 위한 과업 수행

지표 --> 과업

### AARRR: 효율적인 지표관리 프레임워크

사용자의 서비스 이용 흐름을 기반으로 **고객 유치(Acquisition), 활성화(Activation), 리텐션(Retention), 수익화(Revenue), 추천(Referral)** 5단계로 정의하고 각 카테고리별 핵심 지표를 발굴, 측정, 개선하는 지표관리 방법론

![[Pasted image 20260816211518.png|500]]

#### AARRR 활용 방법
1. 각 단계별로 풀어야하는 문제 확인
2. 각 단계의 핵심이 되는 주요 지표 선정 -> 현재 수준 측정
3. 측정된 지표가 가지는 의미 이해
4. 개선 목표 수준 설정 -> 실험을 통해 단계적 개선
